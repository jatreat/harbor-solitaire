# Harbor Solitaire

Classic Klondike solitaire, dealt on a nautical chart of a Maine harbor. Build the four suits up from Ace to King, and stack the tableau down in alternating colors.

- Draw 1 or Draw 3
- Winnable deals: every deal in the default mode has been checked by a solver (you can turn this off)
- Tap a card to send it to the best spot, or drag it; unlimited undo, hints, and a Finish button
- Unlock card backs and tables by winning games

`index.html` is the complete game (one file, CrazyGames HTML5 SDK v3). `covers/` and `videos/` hold the store art.
